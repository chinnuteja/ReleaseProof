# ReleaseProof

ReleaseProof is a durable release agent that prepares a GitHub prerelease from a Linear issue, obtains exact approval in Slack, safely reconciles uncertain external writes, and produces evidence-backed receipts.

The application has not been implemented yet. The authoritative build package is in [`outputs/releaseproof-build/`](outputs/releaseproof-build/00-START-HERE.md). Phase 1 begins with runtime selection, npm workspace setup, strict contracts, configuration safety, durable SQLite storage, provider capability probes, fixtures, and the initial authenticated status screen.
